## GPU 서버 임대 vs 구매, 기준은 사용 시간이다

하루 5시간 안팎으로 GPU를 쓰는 개인이나 소규모 팀이라면 임대가 맞다. 해외 임대 시장에서 H200 NVL(140GB VRAM) 한 대는 시간당 $2.14에 빌릴 수 있는데, 하루 5시간·주 7일 쓴다는 전제로 전기요금, 유지보수, 금리를 모두 반영해 계산하면 구매가 임대보다 나아지는 지점이 2035년 이후로 밀린다. 그동안 GPU 세대가 몇 번이나 바뀌었을지 생각해 보면 답이 나온다.

GPU를 직접 소유하는 게 의미 있는 경우도 있다. 프라이버시와 통제가 중요하고, 서버가 24시간 상시 돌아가는 서비스를 운영할 때다. 짧은 실험을 반복하는 용도에는 이 장점이 발휘될 일이 거의 없다. 레딧의 GPU 임대 토론에서는 GPU 수명을 1~3년으로 보는 의견도 나왔다. 이 가치하락 곡선까지 고려하면 임대 쪽에 무게가 더 실린다.

임대 쪽에는 덜 언급되는 이점도 하나 있다. 서버 시스템, 전력, 업링크 같은 부대비용이 요금에 포함된 상태로 바로 쓸 수 있어서 초기 자본이 아예 들지 않는다. 장비 들여오고 전기·냉각 걱정하는 시간을 그냥 실험에 쓰면 된다.

## GPU 서버 임대 방식 세 가지

GPU 서버 임대는 크게 세 가지로 나뉜다. 가상 서버 형태로 빌리는 클라우드 방식, 물리 장비를 월 단위로 빌리는 호스팅 방식, 그리고 유휴 자원을 저가에 빌리는 커뮤니티·스팟 방식이다.

| 방식 | 과금 단위 | 대표 업체 | 어울리는 용도 |
| --- | --- | --- | --- |
| 클라우드 VM·베어메탈 | 시간 또는 월 | 네이버 클라우드 플랫폼, Vultr | 단기 실험, 유연한 확장 |
| 물리 서버 호스팅 | 월 단위 | 가비아, CLOUDV | 단독 자원, 장기 학습·서비스 운영 |
| 커뮤니티·스팟 | 시간 단위(저가) | Runpod, Vast.ai | 최저가 실험, 안정성 일부 감수 |

클라우드는 사용한 시간만큼만 내면 되고, 물리 호스팅은 성능 전체를 혼자 쓴다. 커뮤니티 방식이 가장 싸지만 스팟 인스턴스는 예고 없이 종료될 수 있다는 조건이 붙는다.

### CLOUDV: 최대 8way 물리 서버, 공개된 건 IDC 요금

LLM 추론용으로는 Ollama, vLLM, KTransformers 같은 프레임워크 기반 사양 제안을 받을 수 있다. 원래 수억 원 대 최상급 멀티 GPU 시스템에서나 돌리던 DeepSeek-R1 671B를 KTransformers로 구동하는 구성도 안내하고 있다.

조건도 하나 붙는다. RTX 4090처럼 GeForce 카드가 장착된 서버를 쓸 때는 NVIDIA의 GeForce 소프트웨어 라이선스를 확인해야 한다. 요금은 원자재와 전기요금 상승에 따라 변동될 수 있다고 안내되어 있다.

### 가비아: 물리 서버 단독 사용, 조건이 가장 명시적인 곳

가비아 GPU 서버호스팅은 GPU 전용 고전력 물리 서버를 다른 사용자와 공유 없이 단독으로 쓰는 방식이다. 클라우드가 아닌 실제 물리 서버고, 세팅 후 root(리눅스) 또는 Administrator(윈도) 어드민 권한을 받는다.

운영 조건이 FAQ로 명시돼 있어서 계약 전에 확인할 게 적다.

- 무약정으로 1개월 단위 이용 가능, 중도 해지 위약금 없음
- 1년 이상 약정 시 상담을 통해 요금 할인
- CPU·메모리 스펙 변경 가능(요금 변동), 판매 목록 외 GPU 모델도 상담으로 확인 가능
- OS는 Ubuntu 설치 제공, 요청 시 해당 GPU에 맞는 최신 드라이버 무상 설치
- CUDA, cuDNN, conda, TensorFlow 등 개발용 라이브러리도 무상 설치 지원
- 회선은 기본 10M에서 10Mbps~1Gbps까지 선택 가능, IP 추가 가능(요금 변동)

소유권이 필요하면 최대 24개월 약정 후 서버를 양도받는 상품이 있다. 다만 무약정 임대형보다 요금이 높다. 반대로 데이터 유출이 걱정돼 서버를 사무실로 가져가는 방법은 없다. 이 상품은 서버 임대료와 IDC 요금이 결합된 형태이고, 서버는 업체 자산이라 외부 반출이 불가능하다. 보안이 걱정되면 방화벽, 웹쉘 탐지, 백신 같은 보안 서비스를 추가하는 방식으로 대응한다.

쿠버네티스 운영용 Kubeflow와 GPU 모니터링용 Grafana 설치·운영 지원은 유료 'GPU 매니지드 서비스'로 제공된다(2025년 신규 출시 예정으로 안내된 상품). 인프라 쪽은 과천 IDC가 2024년 6월 완공된 최신 시설이고, 99.999% 가용성에 20kW 이상 고전력, 전력·공조·네트워크 이중화를 갖추고 있다.

참고로 여러 대를 1개월 단기로 쓰려는 경우, 재고가 없거나 해당 모델 수급이 원활하지 않으면 다수 제공이 어려울 수 있다는 안내가 있다. 단기 다중 GPU가 필요하면 신청 전에 수량 확인부터 하는 게 순서다.

## 해외 GPU 임대 시세: 시간당 $1~2가 고성능 카드 기준선

해외에서는 시간 단위 임대가 표준이고, 고성능 카드 시세는 시간당 $1~2 수준이다. 레딧의 GPU 임대 가격 토론을 정리한 글에 따르면 H100 한 장이 $2/시간, H200 8장 구성이 $16/시간에 거래된다. 더 낮은 가격도 있다. Hyperbolic은 H100을 시간당 $1에 제공하고, Colab Pro는 A100 40GB를 $0.7/시간에 쓸 수 있다.

## 계약 전에 확인할 숨은 비용 다섯 가지

요금표와 청구서 사이에서 놓치기 쉬운 항목들이 비용 차이를 만든다.

1. **IDC 요금의 위치** — CLOUDV처럼 공개 가격이 IDC 요금이고 하드웨어 임대료가 별도인 곳이 있고, 가비아처럼 둘이 결합된 상품인 곳이 있다. 견적을 받으면 반드시 총액 기준으로 비교하라.
2. **트래픽 과금** — 네이버 클라우드는 아웃바운드 트래픽에 별도 과금을 적용한다. 대용량 데이터셋을 밖으로 내보내는 작업이 많다면 이 항목을 먼저 확인하라.
3. **기본 디스크 포함 여부** — 같은 업체 안에서도 하이퍼바이저에 따라 다르다. 네이버 클라우드 기준 KVM 기반(L40S·L4·A100)은 서버 요금에 미포함, XEN 기반(V100·T4)은 포함이다.
4. **스토리지 대기 비용** — Runpod처럼 GPU를 꺼도 볼륨을 유지하면 시간당 약 $0.02가 나온다. 모델과 데이터를 재업로드하는 시간과 비용을 생각하면 싼 편이지만, 방치하면 청구서에 누적된다.
5. **스팟 인스턴스 종료 리스크** — 예고 없이 종료될 수 있으므로 주기적 체크포인팅이 필수다. 중요한 작업은 신뢰도 높은 제공자를, 실험은 저가·스팟으로 나누는 운영이 기본 전략이다.

덧붙이면, 다중 노드 분산 학습을 돌릴 계획이라면 NVLink나 InfiniBand 네트워킹이 보장되는지 확인해야 한다. 이 항목은 요금표에 안 나온다.

## GPU 서버 임대 자주 묻는 질문

### 임대하면 서버를 혼자 쓰게 되나요?

물리 서버 호스팅은 단독 사용이다. 가비아는 GPU 전용 고전력 서버를 공유 없이 제공한다고 명시한다. 클라우드 VM은 가상화 환경이고, 베어메탈(A100 등)은 물리 서버를 단독으로 배정받는다.

### 무약정으로 쓰다가 중도에 해지하면 위약금이 나오나요?

무약정 상품은 나오지 않는다. 가비아는 1개월 단위 이용이 가능하고 중도 해지 위약금이 없다고 안내하며, CLOUDV도 장기 계약 위약금 부담 없는 무약정을 내세운다. 약정은 할인과 소유권 이전을 위해 선택하는 항목이다.

### OS와 딥러닝 라이브러리 설치도 해주나요?

가비아 기준으로 Ubuntu가 설치된 상태로 제공되고, 요청 시 해당 GPU에 맞는 최신 드라이버를 무상으로 설치해 준다. CUDA, cuDNN, conda, TensorFlow 같은 개발용 라이브러리도 무상 설치 지원에 포함된다.

### 학습 데이터 유출이 걱정되는데 어떻게 하나요?

클라우드에서 코드·데이터 프라이버시가 완전히 보장되긴 어렵다. 민감한 데이터와 코드는 로컬이나 온프레미스가 우선이고, 클라우드는 방화벽·웹쉘 탐지·백신 같은 보안 옵션으로 리스크를 줄이는 방식이다. Secure 옵션을 제공하는 커뮤니티 클라우드도 있지만 원천적인 신뢰 문제는 남는다.

### 나중에 서버 소유권을 받을 수 있나요?

가능하다. 가비아는 최대 24개월 약정 후 소유권을 양도받는 상품이 있고(무약정보다 요금이 높음), CLOUDV는 11개월·22개월 기준의 소유권 이전형과 구매형을 제공한다.

## 사용 패턴별 최종 선택

조건별로 딱 잘라 보면 이렇다.

- **하루 몇 시간 실험** → 시간 단위 해외 클라우드. 쓰고 나면 자동 종료 습관만 들이면 된다. 👉 [Vultr에서 시간 단위 GPU 임대 시작하기](https://bit.ly/VulTR)
- **매일 학습을 돌리고 관리 지원이 필요** → 가비아 물리 호스팅을 무약정 1개월 단위로 시작하고, 안정적으로 쓰게 되면 1년 약정으로 요금을 깎는다.
- **A6000 8way 같은 특정 구성, 대용량 VRAM 추론** → CLOUDV에 견적 문의. 이때 하드웨어 임대료에 IDC 요금까지 더한 총액으로 비교한다.
- **회사 규정상 국내 리전이 필수** → 네이버 클라우드 플랫폼에서 L4로 시작해 필요할 때 L40S로 옮긴다.

견적이나 신청 전에 마지막으로 확인할 건 세 가지다. 하드웨어 임대료와 IDC 요금이 어떻게 분리돼 있는지, 아웃바운드 트래픽 과금, 그리고 약정 시 위약금 조건. 이 세 개가 견적서에 명확히 보이면 이후에 곤란해질 일은 거의 없다.
